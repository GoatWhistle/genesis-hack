# Контекст проекта: Hack.Genesis 2026

Этот каталог — единственный источник правды по проекту. Вся переписка и все решения
фиксируются здесь в файлах, а не держатся в контекстном окне модели. Перед любой
работой нужно прочитать нужные файлы отсюда.

## Правила ведения

1. Один файл — одна тема. Номер в имени задаёт порядок чтения.
2. Факты и решения разделены: `10-*` — проверенные факты о хакатоне, `20-*` и далее —
   наши рассуждения, варианты и принятые решения.
3. Любое принятое решение записывается с датой и коротким обоснованием.
4. Ничего не удаляем — отменённые решения помечаем как устаревшие, а не стираем.
5. Факты из внешних источников записываются со ссылкой на источник: для чата хакатона —
   номер сообщения, чтобы утверждение можно было проверить.
6. Всё, что выясняется по ходу основного этапа, идёт в [80-log.md](80-log.md); туда же
   попадают тупики и наблюдения, а не только результаты.

## Статус на 2 сентября 2026

Кейс — генератор интеграций с платёжными провайдерами. Список отобранных команд
опубликован 1 сентября; сверить в нём наше название — задача из
[40-open-questions.md](40-open-questions.md). Разработка
начинается 3 сентября: полное описание задачи в 15:00, открытие в 19:00, QA-сессия
в 19:30. Стопкод 6 сентября в 23:00, питчи финалистов 8 сентября.

Что известно из чата хакатона и влияет на работу: нейросети внутри решения запрещены
(вайбкодинг при разработке разрешён), опенсорсные гемы разрешены, утилиты не на Ruby —
нет, каждый день разработки содержит обязательный десятиминутный чек-поинт с экспертами.
Подробности — [10-hackathon-facts.md](10-hackathon-facts.md).

Ближайшая задача — вопросы к QA-сессии из [40-open-questions.md](40-open-questions.md)
и проверка, что все участники подтвердили участие по ссылке из письма.
