# Контекст проекта: Hack.Genesis 2026

Этот каталог — единственный источник правды по проекту. Вся переписка и все решения
фиксируются здесь в файлах, а не держатся в контекстном окне модели. Перед любой
работой нужно прочитать нужные файлы отсюда.

## Правила ведения

1. Один файл — одна тема. Номер в имени задаёт порядок чтения.
2. Факты и решения разделены: `10-*` — проверенные факты о хакатоне, `20-*` и далее —
   наши рассуждения, варианты и принятые решения.
3. Любое принятое решение записывается с датой и коротким обоснованием.
4. Ничего не удаляем — отменённые решения помечаем как устаревшие, а не стираем.
