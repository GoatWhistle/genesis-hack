## Вопросы к QA-сессии 3 сентября, 19:30

Задавать в порядке важности, времени на сессии час на всех.

1. **Мок-сервер.** Можно ли использовать Prism от Stoplight — утилиту не на Ruby — как
   часть инструмента для проверки сгенерированного кода? Если нет, пишем свой на Ruby.
   Предварительно мы исходим из того, что нельзя, и планируем свой.
2. **Формат сдачи решения.** Репозиторий, архив, видео демонстрации, что-то ещё. Есть ли
   требования к README, лицензии, оформлению коммитов.
3. **Спецификация для проверки.** Будет ли жюри проверять решение на своей
   OpenAPI-спецификации, которую мы заранее не видели. Если да — это меняет приоритеты:
   устойчивость к незнакомому входу становится важнее глубины на знакомом.
4. **Критерии оценки.** Есть ли формальные веса — работоспособность, качество кода,
   покрытие тестами, документация, презентация.
5. **Что считается «заготовкой интеграции».** Насколько готовым должен быть результат
   генерации: компилируемый скелет или работающий код, который можно сразу подключать.
