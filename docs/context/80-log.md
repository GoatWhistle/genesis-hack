# Журнал хода хакатона

Рабочий журнал основного этапа, 3–6 сентября. Пишется по ходу дела: что выяснили, что
сделали, что сломалось, что решили. Отличие от [30-decisions.md](30-decisions.md) —
туда попадают только принятые решения с обоснованием, сюда всё остальное, включая
тупики и наблюдения.

Формат записи: дата и время, короткий заголовок, суть. Новые записи добавляются вниз.
